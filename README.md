# Student Event Registration Formatter

## Description
This program collects student information and event details, then displays them in a clean and organized format.

## Language Used
Python

## String Feature Used
`strip()`, `title()`, `upper()`

## Date/Time Feature Used
`datetime()` and `strftime()`

## Version History
- Version 1: Basic input and output
- Version 2: Added string formatting
- Version 3: Added date formatting

## Sample Output
Student Event Registration Summary

Name: Juan Dela Cruz

Name Code: JUAN DELA CRUZ

Section: MAGNESIUM

Event: Science Fair

Event Date: June 3, 2026

Language Used: Python

String Feature Used: strip(), title(), upper()

Date/Time Feature Used: datetime

Registration record created successfully.

## Reflection
I learned how to use string methods and date formatting in Python. My program improved from displaying basic information to formatting names, sections, and event details. I also learned how to use `datetime` to display dates clearly. Overall, this activity helped me understand how Python can organize and format information.
